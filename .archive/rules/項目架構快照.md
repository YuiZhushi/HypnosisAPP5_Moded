## 頂層目錄概覽

```text
src/
├── 催眠APP前端/      # 核心：OS 主體與所有 APP 的前端介面與業務邏輯
├── 催眠APP監聽/      # 核心：背景腳本，負責監聽酒館關鍵事件並橋接至 iframe
├── 催眠APP脚本/      # 核心：與 UI 無關的遊戲機制腳本（如每日結算、能量恢復）
├── 催眠APP共用/      # 核心：各環境共用的基礎設施（如 loggerService）
├── 催眠APP變量結構/  # 核心：MVU 變量的結構定義與初始註冊
├── 催眠APP世界書/    # 參考：專案關聯的世界書與人設資料（注意：內容已過時，僅供參考，實際內容以酒館端為準）
├── Archive/          # 歸檔：重構前的舊代碼與 AI 回應範例
├── util/             # 工具：底層通用工具函數
├── 界面示例/         # 範例：酒館助手提供的介面開發範例
├── 脚本示例/         # 範例：酒館助手提供的腳本開發範例
└── 角色卡示例/       # 範例：酒館助手提供的角色卡開發範例
```

## 核心前端目錄展開 (`src/催眠APP前端/`)

這是專案最主要的工作區域，嚴格劃分為四個領域驅動層級：`ui` -> `backend` -> `shared` -> `constants`。

```text
src/催眠APP前端/
├── ui/                  # 【UI 層】React 組件，負責畫面渲染與交互
│   ├── os/              # 系統底層 UI (桌面, 狀態列, 導航)
│   ├── home/            # 首頁 APP (Home)
│   ├── settings/        # 設置 APP
│   ├── hypnosis/        # 催眠 APP
│   ├── character-editor/# 角色編輯器 APP
│   ├── achievement/     # 成就與任務 APP
│   ├── calendar/        # 日曆與行程 APP
│   ├── body-stats/      # 身體狀態 APP
│   ├── help/            # 幫助說明 APP
│   └── shared/          # 跨 APP 共用的 UI 組件 (如按鈕、彈窗)
│
├── backend/             # 【後端業務邏輯層】處理各 APP 專屬邏輯與狀態計算
│   ├── settings/
│   ├── hypnosis/
│   ├── character-editor/
│   ├── achievement/
│   ├── calendar/
│   └── body-stats/
│
├── shared/              # 【共用基礎設施層】跨 APP 與底層橋接服務
│   ├── mvu/             # MVU 變數框架通訊 (mvuBridge.ts)
│   ├── store/           # 聊天變數與持久化存儲讀寫
│   ├── worldbook/       # 世界書存取 (worldBookRepository.ts)
│   ├── llm/             # 聊天訊息發送 (chatTransport.ts)
│   ├── ai/              # AI 請求標準管線 (aiRequestPipelineService.ts)
│   ├── listener/        # 事件監聽處理
│   └── access/          # 權限與解鎖檢查
│
└── constants/           # 【常數與資料層】集中管理 Zod Schemas 與預置資料
    ├── schemas/         # 全局 Zod 資料驗證模型 (System, Store)
    ├── common/          # 通用常數 (VIP 等級, 預設值)
    ├── settings/
    ├── hypnosis/
    ├── character-editor/
    ├── achievement/
    └── calendar/
```

## 開發定位指南

1. **要修改畫面排版或新增按鈕？**
   👉 尋找 `src/催眠APP前端/ui/{APP_名稱}/`。

2. **要修改某個 APP 的解鎖條件或扣款邏輯？**
   👉 尋找 `src/催眠APP前端/backend/{APP_名稱}/`。

3. **要新增一項成就、任務或催眠功能定義？**
   👉 尋找 `src/催眠APP前端/constants/{APP_名稱}/` 下的資料庫或 Config 檔案。

4. **要修改與酒館底層變數或世界書的交互方式？**
   👉 尋找 `src/催眠APP前端/shared/` 對應的模組。

5. **要處理酒館的訊息刪除、滑動等事件？**
   👉 尋找 `src/催眠APP監聽/index.ts`。

6. **要修改全域日誌輸出方式？**
   👉 尋找 `src/催眠APP共用/debug/loggerService.ts`。

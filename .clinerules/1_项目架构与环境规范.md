# HypnoOS 項目架構與環境規範

> **核心架構提醒**：本專案採用領域驅動分層架構 (Domain-Driven Layered Architecture)。程式碼運行於酒館助手 (SillyTavern) 的 iframe 中。

---

## 1. 技術棧與環境假設

| 屬性 | 值 |
| :--- | :--- |
| **技術棧** | React + TailwindCSS (v4 全局流暢縮放覆寫) |
| **資料驗證** | Zod (目前定義格式，未來正式上線對接時啟用運行時驗證與補全) |
| **打包工具** | 倉庫根目錄 Webpack（**禁用** Vite 配置） |
| **產物路徑** | `dist/催眠APP前端/index.html` |
| **構建命令** | 倉庫根目錄 `pnpm build:dev` 或 `pnpm build` |

---

## 2. 數據流與架構分層

本專案將開發期與未來上線期的架構與數據流做清晰定義：

### 2.1 開發期數據流：`ui -> MockAPI`
目前專案處於開發測試階段：
* **記憶體載入**：在 iframe 載入時，靜態資料與運行時變數已經加載到記憶體中。
* **UI 隔離**：UI 層**不直接碰觸**任何靜態常數（如 `constants/` 的原始數據）或原始變數，而是**統一通過 MockAPI 接口來存取數據**。

### 2.2 上線期/對接期分層：`ui -> backend -> shared -> constants`
當正式對接 SillyTavern 時，系統將切換為完整的領域驅動四層架構：

1. **`ui/` (前端 UI 層)**
   * **職責**：負責畫面渲染（React Components）與使用者操作交互。
   * **禁忌**：絕對禁止直接操作酒館助手底層 API，禁止操作 `localStorage`、`sessionStorage` 等本地存儲，必須呼叫 `backend/` 提供的 API。
2. **`backend/` (後端業務邏輯層)**
   * **職責**：處理各 APP 專屬的業務邏輯、狀態計算、資料持久化與傳輸。接收 UI 層的意圖並處理。
   * **禁忌**：嚴禁直接操作 DOM 或 React UI 狀態。跨 APP 調用必須經由對應的後端 API。
3. **`shared/` (共用基礎設施層)**
   * **職責**：存放多個 APP 重複使用的底層服務（如 `mvuBridge.ts`、`worldBookRepository.ts`、`aiRequestPipelineService.ts`）。
4. **`constants/` (常數與資料層)**
   * **職責**：集中管理靜態配置、預置資料與 Zod Schemas。
   * **禁忌**：禁止在邏輯或 UI 檔內自行宣告大量常設變數。

* **單向依賴原則**：`ui` -> `backend` -> `shared` -> `constants`。嚴禁循環引用與逆向調用（如 `shared` 依賴 `ui`）。

## 3. 生命週期與載入時機

iframe 的加載與卸載與標準瀏覽器有些許不同：
* **禁止使用 `DOMContentLoaded`**：iframe 載入方式不會觸發此事件。必須使用 jQuery 的 `$(() => { ... })` 來確保正確執行初始化。
* **清理與卸載**：所有清理工作（如取消事件監聽、移除動態掛載的 DOM 等）必須使用 `$(window).on('pagehide', ...)`，**禁止使用 `'unload'` 事件**。

---

## 4. 運行環境與全局變數 (真實對接期)

在酒館的 iframe 運行環境中，以下全局對象**不需要 import，直接可用**：
* `$`：jQuery，僅用於載入時機與事件綁定，注意避免干擾宿主 DOM。
* `Mvu`：MVU 變數框架，用於存取消息樓層變數。
* `getVariables` / `updateVariablesWith` / `replaceVariables`：酒館變數讀寫接口（**UI 層嚴禁調用**）。
* `waitGlobalInitialized` / `eventOn`：事件監聽與初始化工具。
* `createChatMessages` / `triggerSlash`：發送訊息與指令。

## 5. MCP 規則與除錯指南

開發與除錯過程中，必須妥善使用 `chrome-devtools` MCP 工具：
1. **網址配置**：網址與 `.vscode/launch.json` 的 `url` 保持一致。
2. **調試與操作**：
   * 用於獲取當前真實 DOM 結構與 Console 錯誤日誌。
   * 用於模擬點擊和介面操作，驗證畫面。
3. **介面熱重載 (Hot Reload)**：
   * 打開酒館網頁後，確保 `$('#extensions_settings')` 中的「酒館助手-實時監聽-允許監聽」開關處於**啟用**狀態。
   * 熱重載啟用後，程式碼變更會自動重新載入網頁，**不需要手動重新整理網頁，亦不需要在開發中頻繁手動執行 pnpm build**。

---

## 6. 日誌與錯誤處理規範

* **統一前綴**：所有輸出必須使用 `loggerService.ts` 並包含 `[HypnoOS]` 前綴。
* **日誌等級**：關鍵流程與狀態變更使用 `logger.info`；可恢復問題使用 `logger.warn`；無法恢復的致命錯誤使用 `throw Error` 並搭配對應的 Catch 機制處理。
* **禁忌**：禁止使用瀏覽器自帶的彈窗 (Alert/Confirm)，這會中斷對話流程與自動化測試。

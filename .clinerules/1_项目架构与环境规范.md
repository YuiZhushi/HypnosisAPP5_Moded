# HypnoOS 項目架構與環境規範

> **核心架構提醒**：本專案採用 React + TailwindCSS (v4) 架構，程式碼運行於酒館助手 (SillyTavern) 的 iframe 中。目前為開發期，所有數據存取由記憶體模擬庫與 MockAPI 負責。

---

## 1. 技術棧與環境配置

| 屬性 | 值 |
| :--- | :--- |
| **技術棧** | React + TailwindCSS (v4 全局流暢縮放覆寫) |
| **資料定義** | Zod (定義於 `models/index.ts`，預留作未來對接時的運行時校驗) |
| **打包工具** | 倉庫根目錄 Webpack（**禁用** Vite 配置） |
| **產物路徑** | `dist/催眠APP前端/index.html` |
| **構建命令** | 倉庫根目錄 `pnpm build:dev` 或 `pnpm build` |

---

## 2. 目錄結構與職責

專案前端（主要位於 `src/催眠APP前端/`）嚴格劃分為以下層級：

```text
src/催眠APP前端/
├── ui/                  # 【UI 層】React 組件，負責畫面渲染與交互
│   ├── os/              # 系統底層 UI (桌面、導航、狀態列)
│   ├── hypnosis/        # 催眠 APP UI
│   ├── character-editor/# 角色編輯器 APP UI
│   ├── achievement/     # 成就與任務 APP UI
│   └── shared/          # 跨 APP 共用的 UI 組件
│
├── models/              # 【模型與型別層】統一存放所有型別定義與 Zod Schemas
│   └── index.ts         # 全局統一模型定義檔 (如 AppMode, UserResources)
│
├── staticData/          # 【靜態常數層】存放大型靜態配置與預置資料庫
│   └── index.ts         # 全局靜態常數資料庫 (如 Feature 字典、物品字典)
│
├── database/            # 【模擬資料庫層】存放運行時模擬資料與補丁
│   ├── mockDatabase.ts  # 全局模擬變數 (Memory Database) 與載入流程
│   ├── chatVariables.ts # 聊天變數補丁 (chatDatabasePatch)
│   ├── mvuVariables.ts  # MVU 變數補丁 (mvuDatabasePatch)
│   └── characterMockData.ts # 角色與 Prompt 的 Mock 數據
│
└── shared/              # 【共用基礎設施層】跨 APP 與底層橋接/模擬服務
    ├── ai/              # AI 請求標準管線 (aiRequestPipelineService.ts)
    ├── mvu/             # 模擬/真實 MVU 變數同步 (mvuBridge.ts)
    └── store/           # 模擬/真實 Store 讀寫服務
```

## 3. 開發期數據流：`ui -> MockAPI`

目前專案處於開發測試階段，必須遵守以下數據流規範：
* **記憶體載入**：在 iframe 載入時，靜態資料（`staticData/`）與運行時變數已經加載到記憶體中，並由 `database/mockDatabase.ts` 初始化為全域模擬物件。
* **UI 數據隔離**：**UI 層不直接觸碰任何靜態資料或變數，而是統一通過 MockAPI 接口來存取數據。** 
* **依賴方向**：`ui` -> `MockAPI (Models / Database)`。嚴禁 UI 組件內部直接調用底層酒館 API 或操作 `localStorage` 等本地存儲。

---

## 4. 生命週期與載入時機

iframe 的加載與卸載與標準網頁有些許不同：
* **禁止使用 `DOMContentLoaded`**：iframe 載入方式不會觸發此事件。必須使用 jQuery 的 `$(() => { ... })` 來確保正確執行初始化。
* **清理與卸載**：所有清理工作（如取消事件監聽、移除動態掛載元素）必須使用 `$(window).on('pagehide', ...)`，**禁止使用 `'unload'` 事件**。

---

## 5. 運行環境與全局變數 (真實對接期)

在切換回真實酒館的運行環境時，以下全局對象**不需要 import，直接可用**：
* `$`：jQuery，僅用於載入時機與事件綁定，注意避免干擾宿主 DOM。
* `Mvu`：MVU 變數框架，用於存取消息樓層變數。
* `getVariables` / `updateVariablesWith` / `replaceVariables`：酒館變數讀寫接口（**UI 層嚴禁調用**）。
* `waitGlobalInitialized` / `eventOn`：事件監聽與初始化工具。

---

## 6. MCP 規則與除錯指南

開發與除錯過程中，必須妥善使用 `chrome-devtools` MCP 工具：
1. **網址配置**：網址與 `.vscode/launch.json` 的 `url` 保持一致。
2. **除錯與操作**：
   * 用於獲取當前真實 DOM 結構與 Console 錯誤日誌。
   * 用於模擬點擊和介面操作，驗證畫面。
3. **介面熱重載 (Hot Reload)**：
   * 打開酒館網頁後，確保 `$('#extensions_settings')` 中的「酒館助手-實時監聽-允許監聽」開關處於**啟用**狀態。
   * 熱重載啟用後，代碼變更會自動重新載入網頁，**不需要手動重新整理網頁，亦不需要在開發中手動執行 pnpm build**。

---

## 7. 日誌與錯誤處理規範

* **統一前綴**：所有輸出必須使用 `loggerService.ts` 並包含 `[HypnoOS]` 前綴。
* **日誌等級**：關鍵流程與狀態變更使用 `logger.info`；可恢復問題使用 `logger.warn`；致命錯誤使用 `throw Error`。
* **禁忌**：禁止使用瀏覽器自帶的彈窗 (Alert/Confirm)，這會中斷對話流程與自動化測試。

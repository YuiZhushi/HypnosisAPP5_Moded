# 角色編輯器開發說明

本文件說明「角色編輯器」應用程式相關的開發，以及背後 AI 流程的變更指引。

## 1. 角色編輯器 / AI 流程變更

當需要修改角色編輯器或調整相關的 AI 生成流程時，請遵循「食材與食譜」架構與編輯器專用流程：

1. **欄位與資料結構變更**：若新增或移除了角色屬性（如個性、說話風格、背景設定等），需同步更新編輯器的 UI 表單以及後端的資料儲存格式。
2. **修改 Prompt 模組**：管理角色編輯器專用的提示詞設定。若變更了角色的核心設定邏輯，請務必更新傳送給 AI 的 Prompt 結構與系統指令，確保 AI 能正確理解並套用新的設定。
3. **調整構造邏輯**：調整 `buildEditorPipelineParams()` 等函數，確保新流程能正確處理角色卡片、世界書等內容轉換（例如 `yamlToTree` / `treeToYaml` 的 AST 解析）。
4. **AI 生成與套用**：
   - 呼叫後端 API 要求 AI 產生修改建議 (Diff Proposals)。
   - 使用者確認後，將變更合併 (Merge) 套用至角色設定中。
   - 透過 `WorldBookRepository` 儲存變更。
5. **流程驗證**：每次修改後，必須完整走過一次端到端的流程：「建立/修改角色 -> 儲存 -> AI 重新生成/對話測試」，以確保資料格式相容且 AI 的回應符合預期。

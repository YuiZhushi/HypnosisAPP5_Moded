# 成就與任務開發說明

本文件涵蓋專屬應用程式中成就系統與任務模組的開發與維護指引。

## 1. 新增成就/任務

若要在系統中擴充新的成就或任務目標，請依照以下規範：

1. **定義觸發條件**：明確訂定達成任務或成就的具體事件與條件（例如：累積某項操作達特定次數、完成特定劇情等）。
2. **常數層**：在對應的資料庫檔案（如 `questDb.ts` 等）中註冊並添加新的任務或成就資料定義，包含名稱、描述說明、圖示以及對應的獎勵內容。
3. **`backend/` 業務邏輯與事件監聽**：若需要新的成就判定條件，請在後端邏輯中實作檢查與判定。並在相關系統模組中埋設事件觸發點，當玩家滿足條件時，透過 MVU 橋接進行狀態更新與進度通知。
4. **自定義任務**：若為玩家自訂任務，可透過後端 API 進行發布、承接、取消與結算等管理。
5. **`ui/` 前端組件與回饋**：任務與成就列表通常會自動渲染，若有特殊的進度顯示需求，需在 UI 檔案中進行額外處理與條件判斷。確保當成就解鎖或任務完成時，應用程式能正確彈出提示通知（Toast / Popup），並且在成就清單頁面中，該項目能即時更新為已解鎖狀態。

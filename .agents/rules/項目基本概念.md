# HypnoOS 項目基本概念

HypnoOS 是一個專為酒館助手 (Tavern Helper) 設計的前端介面與腳本專案。它在酒館 (SillyTavern) 中以 iframe 形式運行，提供了一個偽手機 OS 風格的「催眠」遊戲體驗。

本專案近期經歷了重大的架構重構，已全面採用**領域驅動分層架構 (Domain-Driven Layered Architecture)**。

## 1. 核心技術棧

* **UI 框架**：**React** (已全面廢棄 Vue)
* **樣式設計**：**TailwindCSS** (優先使用原子類，避免散落的全局 CSS)
* **打包工具**：Webpack (於倉庫根目錄執行，**不使用** Vite)
* **資料驗證**：Zod 4 (強制用於所有持久化資料與 MVU 變數的驗證與糾錯)
* **語言**：TypeScript (強制要求，不使用純 JavaScript)

## 2. 領域驅動分層架構 (Domain-Driven Layered Architecture)

為了確保各個 APP 模組的獨立性、可維護性與資料流的清晰，專案程式碼（主要位於 `src/催眠APP前端/`）嚴格劃分為四個主要層級。

### 2.1 `ui/` (前端 UI 層)
*   **職責**：負責畫面渲染（React Components）與使用者操作交互。
*   **限制**：
    *   只能依賴 `shared/` 與 `constants/`。
    *   **絕對禁止**直接匯入或呼叫 `backend/` 的內部邏輯。
    *   **絕對禁止**直接調用酒館助手的底層 API（如 `getVariables`）。
    *   **絕對禁止**直接操作 `localStorage`, `sessionStorage`, `indexedDB`。

### 2.2 `backend/` (後端業務邏輯層)
*   **職責**：處理各 APP 專屬的業務邏輯、狀態計算、資料持久化與傳輸。
*   **限制**：
    *   負責接收 UI 層的意圖（Intent）並處理。
    *   **嚴禁**直接操作 DOM 或 React UI 狀態。
    *   如需訪問其他 APP 的功能，必須透過該 APP 後端提供的 API 進行。

### 2.3 `shared/` (共用基礎設施層)
*   **職責**：存放多個 APP 重複使用的底層服務與橋接工具。
*   **核心模組**：
    *   `mvuBridge.ts`：負責與 MVU 變數框架安全通訊。
    *   `worldBookRepository.ts`：統一處理世界書的讀寫。
    *   `aiRequestPipelineService.ts`：統一處理 AI 請求的拼接與發送。
    *   `chatTransport.ts`：處理聊天訊息的發送。

### 2.4 `constants/` (常數與資料層)
*   **職責**：集中管理各 APP 的大量常數、預置資料與 Zod Schemas。
*   **限制**：禁止在業務邏輯或 UI 檔案內自行宣告大量常設變數。

## 3. 單向依賴與防循環引用

開發時必須嚴格遵守單向依賴原則：
**`ui` -> `backend` -> `shared` -> `constants`**

*   嚴禁檔案間的循環引用。
*   嚴禁跨層級逆向引用（例如：`shared` 絕對不能依賴 `ui`）。
*   嚴禁跨 APP 的直接內部引用（必須透過 API）。

## 4. 運行環境與全局變數

程式碼運行於 iframe 中，部分全局對象可直接使用（不需 import）：

* **`$` (jQuery)**：僅用於載入時機與事件綁定。**注意：** `$` 運作於整個 SillyTavern 的 DOM，而不僅僅是 iframe 內部，請小心使用避免干擾宿主。
* **`Mvu`**：MVU 變數框架。
* **注意**：`getVariables` 等酒館變數介面雖為全局可用，但在新架構中，**UI 層嚴禁直接調用**，必須交由 Backend/Shared 層處理。

## 5. 最佳實踐與開發規範

1. **資料與狀態管理**：廢棄 Pinia，改用 React Hooks (`useState`, `useEffect`) 結合 Backend API 進行狀態管理。所有持久化資料必須透過 Zod 進行驗證。
2. **事件驅動**：利用 `Mvu.events.VARIABLE_UPDATE_ENDED` 等事件作為 UI 重新拉取資料與刷新的觸發器，嚴禁雙向綁定。
3. **載入與卸載時機**：
   * **禁止使用 `DOMContentLoaded`**，必須使用 jQuery 的 `$(() => { ... })` 來確保在 iframe 環境中正確執行初始化。
   * **清理工作**：必須使用 `$(window).on('pagehide', ...)` 來清理事件監聽器或移除注入的 DOM 元素，**禁止使用 `'unload'`**。
4. **日誌記錄**：統一使用 `@src/催眠APP共用/debug/loggerService.ts` 進行日誌輸出，並加上 `[HypnoOS]` 前綴。遇到致命錯誤時應使用 `throw Error` 並搭配 `errorCatched` 處理。

## 6. 資源載入與第三方庫

* **第三方庫**：專案已包含 `react`, `zod`, `jquery`, `lodash`, `gsap` 等庫。前端介面或腳本都在瀏覽器中執行，**嚴禁使用 NodeJS 庫**。
* **導入檔案內容 (`?raw`)**：專案支援使用 `import content from './file?raw'` 將檔案內容作為字串導入。若導入的是 `.ts` 或 `.scss`，將會是經過 Webpack 打包後的純 JS/CSS。
